# ПЕРЕДАЧА ПРОЕКТА В НОВЫЙ ЧАТ

## Задание новому исполнителю

Продолжить разработку Android-приложения TurnikCoach по документу `docs/TZ_TurnikCoach.md`.

Не начинать разработку заново. Использовать исходники и историю Git из настоящего архива.

Репозиторий: https://github.com/petrkyzmin2026-sys/TurnikCoach

## Обязательный порядок работы

1. Изучить `docs/TZ_TurnikCoach.md`.
2. Проверить текущий код и сборочные сценарии.
3. Подготовить интерактивный предпросмотр согласуемых изменений.
4. Проверить все кнопки предпросмотра.
5. После согласования внести изменения в Android-проект.
6. Выполнить автоматические проверки.
7. Установить APK на Android-эмулятор или устройство.
8. Пройти цикл «Тренировка 1 → Тренировка 2 → Тренировка 3 → Контрольный замер → Тренировка 1».
9. Проверить досрочное завершение, пропуск, звуки, графики и историю.
10. Только после успешной проверки выдать APK.

## Запреты

- Не выдавать существующую сборку под новым номером.
- Не заменять работающие кнопки изображением интерфейса.
- Не изменять коэффициенты авторской системы без подтверждённого источника.
- Не объявлять проверку выполненной без фактического прохождения.
- Не подписывать эксплуатационную сборку ключом из открытого репозитория.
